# Кешуючий проксі-сервер для http.cat

Лабораторна робота №5. HTTP-сервер на Node.js (модуль `http`), який віддає картинки котів
з https://http.cat і кешує їх на диску. Увесь асинхронний код написано на промісах і async/await.

## Запуск

```bash
npm install
node main.js -h 127.0.0.1 -p 3000 -c ./cache
```

| Опція | Призначення |
|---|---|
| `-h, --host <address>` | адреса сервера (обов'язкова) |
| `-p, --port <number>` | порт (обов'язкова) |
| `-c, --cache <path>` | тека кешу, створюється автоматично (обов'язкова) |

## API

| Запит | Відповідь |
|---|---|
| `GET /NNN` | 200 + `image/jpeg`; заголовок `X-Image-Source: cache` або `http.cat`; 404 якщо картинки немає |
| `PUT /NNN` (тіло — картинка) | 201; 400 якщо тіло порожнє; 413 якщо більше 10 МБ |
| `DELETE /NNN` | 200; 404 якщо картинки немає в кеші |
| інший метод | 405 + заголовок `Allow: GET, PUT, DELETE` |
| неправильний шлях | 400 |

## Файли

- `main.js` — сервер
- `test.txt` — команди curl і їхній вивід
- `caching-proxy.postman_collection.json` — колекція Postman з тестами
- `test-images/my-cat.jpg` — власна картинка для PUT
